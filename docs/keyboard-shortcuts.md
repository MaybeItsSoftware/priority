# Desktop keyboard shortcuts

The desktop uses [Checkvist’s shortcuts](https://checkvist.com/help) for matching actions. Type two-letter commands in succession while navigating tasks or the sidebar. Prefixes expire after 1.2 seconds and clear when focus moves or text editing begins. Text fields retain their normal macOS editing shortcuts.

| Keys | Action |
| --- | --- |
| `uu`, Cmd Z, Ctrl Z | Undo the last complete action |
| Cmd Shift Z, Ctrl Shift Z | Redo |
| `ee`, F2 | Edit title; F2 also renames sidebar lists/folders |
| `dd` | Edit due date |
| `td`, `tm`, `cd` | Due today, tomorrow, or clear due date |
| `nn`, `cn` | Edit or clear notes |
| `tt`, `ct` | Edit or clear tags |
| `dr` | Edit repeating due settings |
| `mm` | Move selected task or sidebar list |
| `ll` | Find/open a list, or create a new list |
| `gh` | Open Everything in the sidebar |
| `hc` | Hide/show completed and invalidated tasks |
| `sd` | Show/hide inspector details |
| `oo` | List/folder settings |
| `pc` | Show task progress in the inspector |
| `xx` | Extract a branch as a standalone list |
| `gg` | Open the first linked URL |
| `0`–`9` | Set priority; zero clears it |
| Space, Shift Space | Complete/reopen, or invalidate/reopen |
| Tab, Shift Tab | Indent/outdent on the task surface |
| Cmd Up/Down, Ctrl Up/Down | Reorder selected task/list/folder |
| Home, End, Page Up/Down | Move to either end or eight rows at a time |
| Shift Right/Left | Open selected branch / return to its parent |
| Enter, Alt Enter, Shift Enter | In outline: add below, above, or as a child |
| `/`, Cmd F | Search all tasks |
| `?`, Cmd `/`, Shift Shift | Keyboard reference |
| Alt T, Alt S | Edit estimate or start date |

The board keeps Left/Right for column navigation, including empty columns. Enter opens a selected task’s nested board, or focuses the add-task field in an empty column. Alt Enter and Shift Enter add above/as a child in the board too. Escape cancels task entry and returns to navigation.

Undo is available in Edit and in the sidebar’s history menu, which names the action being undone/redone. History persists across launches and retains the latest 100 complete actions. Creating a board card, assigning its column and placing it at the top undo together; card placement and column removal also undo as complete actions. Undo/redo reveals restored work and clears selections/scopes that no longer exist. Saved edits are undoable; unsaved inspector drafts remain drafts. Completing a focus task can reopen with undo while its elapsed time and points remain recorded. Timer records stay outside edit history.
