Takt

Plan the day, then do it. Takt is the gold standard of easy-to-use open source software — a free task manager for Mac, iPhone, iPad, Android, Wear OS and the terminal.

Source code: github.com/MaybeItsSoftware/priority, under the GNU AGPL-3.0.

What it does

  • A Today list ranked for you — planned, overdue, due and dailies — with when you'll finish.
  • Lists that fold like an outline, the same tasks as a board, and an urgent/important matrix.
  • Focus timers on the task in hand; tap a task to finish it.
  • Type it the way you'd say it: 45m @fri #work !1 fills in the details.
  • Works fully offline with no account. Keyboard-first on the Mac; a command line and terminal UI too.
  • An MCP server so an AI assistant can read and plan your tasks with you.
